Help & Support Support

1. How do I buy products?

Go to Product Marketplace, choose a product, click Buy Now, and confirm the order in the popup. In demo mode, a sample order is created instantly.

2. How do deposits work?

Use the deposit form to submit a request with method and reference. The demo is only for UX testing. Secure validation happens in a real backend.

3. Is this secure?

No. This is a frontend demo only. Authentication, payment processing, and sensitive data must be handled by a secure backend and database.

FAQ Common Queries

No. Demo withdrawals are simulation only and do not transfer real funds.

Yes, use the Reset Demo Data button in the Profile page.
